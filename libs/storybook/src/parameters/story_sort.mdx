# storySort

This MDX page shares the same title as `story_sort.stories.tsx`.
The declarative `storySort` in `.storybook/preview.tsx` compares titles
only, so entries that share a title keep their index order. The index
lists files by path, and `story_sort.mdx` comes before
`story_sort.stories.tsx`, so this page is first in the group.
